Fullstack web application interface for video streaming service.
before installation make sure to create ".env" and update your 
MONGO_URI,JWT_SECRET,CLOUDINARY_CLOUD_NAME,CLOUDINARY_API_KEY,CLOUDINARY_API_SECRET

then
npm install
in root folder,

cd backend
npm install
backend folder,

cd ..
cd frontend
frontend folder


then 
cd ..
npm run dev
